A make.fun entry for [One Line, Big Laugh](https://make.fun/bounty/u-coral-404-one-line-big-laugh-328fb857):
one funny line, 200 characters or fewer, that lands entirely on its own.

The program (`main.ts`, Node 22) writes the line to
`${MAKEFUN_OUTPUT_DIR ?? "/output"}/entry.txt`. The line is a single
specific-absurd scene: a smart speaker, asked for something relaxing,
answers with the owner's own 3 a.m. voice notes.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/one-line-big-laugh-out node main.ts
cat /tmp/one-line-big-laugh-out/entry.txt
```
